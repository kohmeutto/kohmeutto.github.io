de Rham 코호몰로지

1. 동기: 폐형식과 완전형식의 차이

§8 에서 외미분의 두 핵심 개념을 도입했다 — 폐형식 (closed form) 과 완전형식 (exact form).

폐형식은 외미분이 0 인 형식: $d\omega = 0$.

완전형식은 다른 형식의 외미분으로 표현되는 형식: $\omega = d\eta$ 인 $\eta$ 가 존재.

$d^2 = 0$ 으로 완전 → 폐 는 항상 성립. 즉 모든 완전형식은 폐형식.

그런데 역 — 모든 폐형식이 완전형식인가? — 은 공간의 위상에 따라 다르다. 이게 §8 §10, §9 §8, §11 §13 에서 반복적으로 등장한 핵심 사실.

놀라운 깨달음

폐형식이지만 완전형식이 아닌 형식들이 얼마나 많이 존재하는가 가 공간의 위상학적 정보 를 정확히 측정 한다는 것.

폐형식 / 완전형식의 비율 = 공간의 위상학적 정보

이 비율 (quotient) 을 정확히 정의한 것이 de Rham 코호몰로지 (de Rham cohomology).

이 장에서 그 정의, 의미, 그리고 왜 미적분의 도구가 위상수학과 연결되는지 를 본다. 결과적으로 외미분 $d$ 가 단순한 미분 연산자가 아니라 공간의 모양 (shape) 을 측정하는 도구 임이 드러난다.

2. 코사슬 복합체

먼저 우리가 다루는 기본 구조 를 정확히 짚는다.

§9 §6 에서 본 de Rham 사슬 을 다시 보자.

$$\Omega^0(M) \xrightarrow{d} \Omega^1(M) \xrightarrow{d} \Omega^2(M) \xrightarrow{d} \cdots \xrightarrow{d} \Omega^n(M)$$

이게 코사슬 복합체 (cochain complex) 라 부르는 구조. 핵심 성질이 연속된 두 화살표의 합성이 0:

$$d \circ d = 0$$

이걸 $d^2 = 0$ 으로 짧게 쓴다.

코사슬 복합체에서 두 부분공간을 정의한다.

$k$-cocycle (폐 $k$-형식)

$Z^k(M) := \{\, \omega \in \Omega^k(M) : d\omega = 0 \,\}$

외미분이 0 인 $k$-form 들의 공간. 즉 폐형식의 공간.

$k$-coboundary (완전 $k$-형식)

$B^k(M) := \{\, \omega \in \Omega^k(M) : \omega = d\eta \text{ for some } \eta \in \Omega^{k-1}(M) \,\}$

다른 $(k-1)$-form 의 외미분으로 표현되는 $k$-form 들의 공간. 즉 완전형식의 공간.

$d^2 = 0$ 으로 $B^k(M) \subseteq Z^k(M)$ 가 항상 성립. 모든 완전형식은 폐형식.

코호몰로지 군

폐형식의 공간을 완전형식의 공간으로 나눈 몫 공간:

$$\boxed{\;\; H^k(M) := Z^k(M) \,/\, B^k(M) \;\;}$$

이 몫 벡터 공간 을 $M$ 의 $k$-차 de Rham 코호몰로지 군 (k-th de Rham cohomology group) 이라 부른다 (군이지만 사실은 벡터 공간).

직관적 의미:

$H^k(M)$ = 완전이 아닌 폐 $k$-form 들의 동치류 (equivalence class)

두 폐형식 $\omega_1, \omega_2$ 가 동치 라는 건 그 차이가 완전형식: $\omega_1 - \omega_2 = d\eta$. 이런 동치류의 집합이 $H^k(M)$.

3. 가장 단순한 경우: $\mathbb{R}^n$

먼저 가장 단순한 다양체 인 $\mathbb{R}^n$ 의 코호몰로지를 본다. 결과가 놀라울 정도로 간단.

Poincaré 보조정리 (Poincaré lemma)

정리: $\mathbb{R}^n$ 위에서, $k \ge 1$ 일 때 모든 폐 $k$-form 은 완전형식.

따라서

$$H^k(\mathbb{R}^n) = 0 \quad \text{for } k \ge 1$$

$k = 0$ 일 때는 약간 다르다. 0-form (함수) $f$ 가 폐 ($df = 0$) 라는 건 $f$ 가 상수 라는 뜻 (모든 편미분이 0 이므로). 완전형식이라는 건 어떤 $(-1)$-form 의 외미분 이지만 $(-1)$-form 은 정의되지 않으므로 완전형식이 없음. 따라서

$$H^0(\mathbb{R}^n) = \{\text{상수 함수의 공간}\} \cong \mathbb{R}$$

($\mathbb{R}^n$ 이 연결되어 있으므로 상수 함수가 1차원.)

증명 아이디어

$\omega$ 가 $\mathbb{R}^n$ 의 폐 $k$-form 일 때, 원점에서 각 점으로 가는 직선 경로 를 따라 적분 함으로써 $\eta$ 를 만들 수 있다. 볼록한 영역의 핵심 성질 이 이 구성을 가능하게 함.

자세한 증명은 Cartan 의 magic 공식 을 사용한 호모토피 인자 (homotopy operator) 로 한다.

결론

$$H^k(\mathbb{R}^n) = \begin{cases} \mathbb{R} & k = 0 \\ 0 & k \ge 1 \end{cases}$$

$\mathbb{R}^n$ 은 코호몰로지적으로 자명 — 위상학적으로 수축 가능 (contractible) 한 공간의 특징.

4. 첫 번째 비자명한 예: 원 $S^1$

이제 수축 가능하지 않은 가장 단순한 다양체 — 원 $S^1$ — 을 본다.

예: $S^1$ 위의 각도 1-form

§11 §13 에서 본 예를 다시. 원 위의 각도 1-form $d\theta$ 는 폐형식이지만 완전형식이 아니다.

폐형식인 이유: 좌표 표현으로 $d\theta = (-y\, dx + x\, dy)/(x^2 + y^2)$ (원점 근방 제외), 직접 계산으로 $d(d\theta) = 0$.

완전형식이 아닌 이유: §11 §13 의 둘레 적분

$$\oint_{S^1} d\theta = 2\pi \neq 0$$

이 글로벌 함수 $\theta$ 가 없음 을 보여줌. (만약 $d\theta = df$ 이면 Stokes 정리로 적분이 0 이어야 함.)

$H^1(S^1) = \mathbb{R}$

이 예에서 비자명한 폐형식의 모든 가능성 은 $d\theta$ 의 스칼라 배. 다른 형식들은 $d\theta$ 와 완전형식만큼 차이 가 있을 뿐.

따라서

$$H^1(S^1) = \mathbb{R} \cdot [d\theta] \cong \mathbb{R}$$

(1차원 벡터 공간.)

전체 $S^1$ 의 코호몰로지

  • $H^0(S^1) = \mathbb{R}$ (연결된 공간)
  • $H^1(S^1) = \mathbb{R}$ ($d\theta$ 의 동치류)
  • $H^k(S^1) = 0$ for $k \ge 2$ ($S^1$ 이 1차원이므로)

해석

$H^1(S^1) = \mathbb{R}$ 이 0 이 아닌 것이 원에 1차원 구멍 (hole) 이 하나 있음 을 대수적으로 측정. 원을 한 바퀴 돌면 시작점으로 돌아오지만 그 사이의 경로가 단순하지 않음 — 이 위상학적 사실이 코호몰로지에 명시적으로 인코딩.

5. 두 번째 예: 원점이 빠진 평면 $\mathbb{R}^2 \setminus \{0\}$

비슷한 비자명성을 가진 다른 예가 원점이 빠진 평면. 이 공간이 원과 같은 코호몰로지 를 가짐을 본다.

1-form $\omega$ 의 예

$\omega = (-y\, dx + x\, dy)/(x^2 + y^2)$. 이건 $\mathbb{R}^2 \setminus \{0\}$ 에서 잘 정의된 1-form.

폐형식인지 확인: 계산해 보면 $d\omega = 0$.

완전형식인지? 만약 $\omega = df$ 라면 원점을 둘러싸는 폐곡선 위의 적분이 0 이어야 함. 그런데 단위원 위의 적분은 (§10 §6 의 결과)

$$\oint_{S^1} \omega = 2\pi \neq 0$$

따라서 완전형식이 아님.

$H^1(\mathbb{R}^2 \setminus \{0\}) = \mathbb{R}$

위의 예가 사실 원 $S^1$ 의 예와 같은 코호몰로지 정보. 원점이 빠진 평면이 원 $S^1$ 과 위상학적으로 동등 (호모토피 동치) 이기 때문.

구체적 응용: 보존이 아닌 비회전 벡터장

이 1-form 에 대응하는 벡터장:

$$\vec{F} = \left( -\frac{y}{x^2 + y^2},\, \frac{x}{x^2 + y^2} \right)$$

이게 비회전 ($\nabla \times \vec{F} = 0$) 이지만 보존이 아닌 대표적 벡터장. §9 §8 에서 언급한 예의 정확한 표현.

공간의 위상 (원점이 빠짐) 이 벡터장의 보존성을 깨뜨림. 코호몰로지가 이걸 정량적으로 측정.

6. 더 복잡한 예: 토러스 $T^2$

토러스 (torus, 도넛 모양 표면) 의 코호몰로지는 더 풍부하다.

토러스의 표현

토러스 $T^2 = S^1 \times S^1$ 은 두 원의 곱. 두 매개변수 $\theta, \phi \in [0, 2\pi]$ 로 표현, 각각 주기적.

기본 폐 1-form 들

토러스 위의 두 가지 자연스러운 폐 1-form: $d\theta$ 와 $d\phi$.

각각이 완전형식이 아닌 이유는 §11 §13 의 원의 예와 같다. 두 서로 다른 둘레 (사이클) 를 따라 둘레 적분이 $2\pi$.

$H^1(T^2) = \mathbb{R}^2$

따라서 토러스의 1차 코호몰로지는 2 차원:

$$H^1(T^2) = \mathbb{R} \cdot [d\theta] \oplus \mathbb{R} \cdot [d\phi] \cong \mathbb{R}^2$$

토러스의 두 독립적인 사이클 에 대응.

$H^2(T^2)$

2-form 도 비슷하게: $d\theta \wedge d\phi$ 가 폐형식이지만 완전형식이 아님.

$$H^2(T^2) = \mathbb{R}$$

토러스의 전체 부피 형식 에 대응.

전체 토러스 코호몰로지

$$H^0(T^2) = \mathbb{R}, \quad H^1(T^2) = \mathbb{R}^2, \quad H^2(T^2) = \mathbb{R}$$

Euler 표수 (Euler characteristic) $\chi(T^2) = 1 - 2 + 1 = 0$ — 토러스의 0 인 Euler 표수 의 직접 확인.

7. Betti 수와 위상 불변량

위에서 본 $\dim H^k(M)$ 을 Betti 수 (Betti number) $b_k$ 라 부른다.

$$b_k(M) := \dim H^k(M)$$

Betti 수는 위상학적 불변량 (topological invariant) — 두 공간이 위상학적으로 같으면 (호모토피 동치) 같은 Betti 수.

해석

  • $b_0(M)$ = 공간의 연결 성분 (connected component) 의 수.
  • $b_1(M)$ = 1차원 구멍 (loops not contractible) 의 독립 개수.
  • $b_2(M)$ = 2차원 구멍 (속이 빈 표면) 의 수.
  • $b_k(M)$ = $k$-차원 구멍의 독립 개수.

따라서 코호몰로지가 공간의 모양 (구멍의 구조) 을 측정.

예시

  • $\mathbb{R}^n$ (수축 가능): $b_0 = 1$, 나머지 모두 0. 구멍 없음.
  • 원 $S^1$: $b_0 = 1, b_1 = 1$. 1차원 구멍 하나.
  • 구면 $S^2$: $b_0 = 1, b_1 = 0, b_2 = 1$. 2차원 구멍 하나 (속이 빈 공).
  • 토러스 $T^2$: $b_0 = 1, b_1 = 2, b_2 = 1$. 1차원 구멍 둘 (두 사이클), 2차원 구멍 하나.
  • $n$-구면 $S^n$: $b_0 = b_n = 1$, 나머지 모두 0.

Euler 표수

Euler 표수가

$$\chi(M) = \sum_{k=0}^{n} (-1)^k\, b_k(M)$$

으로 정의되며 위상학적 불변량. 토폴로지의 가장 중요한 정수 불변량 중 하나.

8. 호모토피 불변성

de Rham 코호몰로지의 놀라운 성질 이 호모토피 불변성.

정의 (호모토피 동치)

두 공간 $M, N$ 이 호모토피 동치 (homotopy equivalent) 라는 건, 연속적으로 서로 변형 가능 — 즉 양방향 매끄러운 함수 $f: M \to N$, $g: N \to M$ 이 있어서 $f \circ g$ 와 $g \circ f$ 가 각각 항등 함수와 연속적으로 연결됨.

정리: $M$ 과 $N$ 이 호모토피 동치이면 $H^k(M) \cong H^k(N)$ 모든 $k$ 에 대해.

의미

연속 변형으로 같아지는 공간들은 코호몰로지도 같다. 따라서 코호몰로지가 진정한 위상학적 정보를 측정 한다.

예: 원점이 빠진 평면 $\mathbb{R}^2 \setminus \{0\}$ 가 원 $S^1$ 과 호모토피 동치 — 평면을 원점에서 멀어지는 방향으로 연속 변형해 원으로 만들 수 있음. 따라서 같은 코호몰로지.

비슷하게 수축 가능 (contractible) 한 공간 — 즉 한 점으로 연속 변형 가능 한 공간 — 은 점과 같은 코호몰로지: $H^0 = \mathbb{R}$, 나머지 모두 0.

9. de Rham 정리

de Rham 코호몰로지의 진정한 깊이 는 다른 위상학적 도구와의 완벽한 일치 에 있다.

de Rham 정리 (de Rham theorem): 매끄러운 다양체 $M$ 에 대해, de Rham 코호몰로지 는 특이 코호몰로지 (singular cohomology) 와 정확히 일치.

$$H^k_{\text{dR}}(M) \cong H^k_{\text{sing}}(M; \mathbb{R})$$

특이 코호몰로지는 순수 위상학적 (미분 구조 무관) 도구. 그런데 미분형식으로 정의된 de Rham 코호몰로지가 이것과 일치 — 이건 미적분과 위상수학의 깊은 통일.

증명의 핵심: Stokes 정리 — 매끄러운 다양체의 적분이 호모토피 사슬과 자연스럽게 짝지어짐 — 가 두 코호몰로지 간의 자연스러운 동형사상 을 만든다.

의미: 미분 (해석학적) 도구가 위상 (대수적) 정보를 인코딩. 외대수 언어가 위상수학의 자연스러운 도구 임이 정확히 확립.

10. 물리적 응용 1: Aharonov-Bohm 효과

de Rham 코호몰로지가 물리에서 직접 등장 하는 가장 유명한 예가 Aharonov-Bohm 효과.

설정

전자가 자기 솔레노이드 (solenoid) 의 바깥 영역을 지나는 실험. 솔레노이드 안에는 자기장이 있지만 바깥에는 자기장이 0.

고전적 직관: 전자가 자기장과 상호작용하지 않음 — 솔레노이드의 영향을 받지 말아야 함.

실제 결과

양자역학에서 전자의 위상 (phase) 이 영향을 받음.

이유: 벡터 포텐셜 $\vec{A}$ 가 솔레노이드 바깥에서도 0 이 아님. 폐형식 ($\nabla \times \vec{A} = 0$ 즉 $d \vec{A}^\flat = 0$) 이지만 완전형식이 아님 (솔레노이드 주변의 호 적분이 0 이 아님).

이게 정확히 비자명한 $H^1$ 의 사례 — 솔레노이드 주변 공간이 원점이 빠진 평면 같은 위상 을 가짐.

미분형식 해석

전자의 위상이 Wilson loop (1-form 의 호 적분)

$$\phi = \oint_C \vec{A} \cdot d\vec{r} = \oint_C \vec{A}^\flat$$

로 변화. Stokes 정리로

$$\oint_C \vec{A}^\flat = \int_S d\vec{A}^\flat = \int_S \star \vec{B}^\flat = \text{자기 플럭스}$$

(단, $S$ 가 경로 안쪽의 면이며 솔레노이드를 포함. 솔레노이드의 자기 플럭스가 들어감.)

솔레노이드 안의 자기장이 솔레노이드 바깥의 전자 위상에 영향 — 코호몰로지를 통해 매개.

이 위상학적 효과 가 비자명한 $H^1(M)$ 에서 정확히 나옴.

11. 물리적 응용 2: 자기 모노폴

자기 모노폴 (Dirac monopole) 의 존재성 가설도 코호몰로지의 자연스러운 응용.

설정

자기 모노폴 (자기장의 점원) 이 원점에 있다고 하자. 자기장:

$$\vec{B} = \frac{q_m}{4\pi r^2}\, \hat{r}$$

($q_m$ = 자기 전하.)

문제

$\nabla \cdot \vec{B} \neq 0$ (원점에서). 일반적으로 Maxwell 의 한 방정식 $\nabla \cdot \vec{B} = 0$ 와 모순.

미분형식 해석: $B$ 의 2-form $\eta_B = \star \vec{B}^\flat$ 가 원점을 뺀 영역에서 폐형식 ($d\eta_B = 0$, 원점 외에서 $\nabla \cdot \vec{B} = 0$).

하지만 글로벌 벡터 포텐셜 $\vec{A}$ 가 존재하지 않음 — 즉 $\eta_B$ 가 완전형식이 아님. 이게 $H^2(\mathbb{R}^3 \setminus \{0\}) = \mathbb{R}$ 의 표현.

Dirac 의 해결

Dirac 이 두 좌표 패치 로 $\vec{A}$ 를 각 패치에서 따로 정의 하고, 두 패치의 경계에서 게이지 변환 으로 연결하는 방법 제안. 이때 양자역학의 위상의 일관성 이 Dirac 양자화 조건

$$e \cdot q_m = 2\pi n \quad (n \in \mathbb{Z})$$

을 요구. 전기 전하의 양자화와 자기 전하의 양자화가 연결됨 — 코호몰로지의 정수 구조에서 자연스럽게.

이게 de Rham 코호몰로지가 양자화 조건을 인코딩 하는 예.

12. NEGF · 응집계 물리와의 연결

코호몰로지가 응집계 물리, 위상 절연체 등에서도 핵심 역할.

Chern 수와 Berry 곡률

위상 절연체 와 양자 홀 효과 에서 Chern 수 가 등장. 이게 Brillouin 영역 (BZ) 위의 2-form (Berry 곡률) 의 적분

$$C = \frac{1}{2\pi} \int_{BZ} F$$

여기서 $F = dA$ 가 Berry 곡률 2-form (벡터 포텐셜 1-form $A$ 의 외미분).

$F$ 가 폐형식 ($dF = 0$, $d^2 = 0$ 으로) 이지만 글로벌하게 완전형식이 아닐 수 있음. Chern 수가 그 비자명성을 측정 하는 정수 위상 불변량.

NEGF 와 직접 연결: 위상 절연체의 응답 함수 가 Berry 곡률을 포함, 이게 de Rham 코호몰로지의 직접 응용.

13. 정리

이 장에서 다룬 내용을 정리한다.

1) de Rham 코호몰로지: $H^k(M) := Z^k(M) / B^k(M)$ — 폐형식 / 완전형식 의 몫.

2) Poincaré 보조정리: $\mathbb{R}^n$ (또는 수축 가능한 공간) 위에서 모든 폐형식이 완전형식. $H^k(\mathbb{R}^n) = 0$ ($k \ge 1$).

3) $S^1$ 의 코호몰로지: $H^1(S^1) = \mathbb{R}$ — 1차원 구멍의 존재를 측정.

4) Betti 수 $b_k = \dim H^k(M)$ — 공간의 위상학적 구멍의 독립 개수.

5) Euler 표수 $\chi(M) = \sum_k (-1)^k b_k(M)$ — 위상학적 불변량.

6) 호모토피 불변성: 호모토피 동치인 공간들은 같은 코호몰로지.

7) de Rham 정리: de Rham 코호몰로지 = 특이 코호몰로지 — 해석학과 위상수학의 통일.

8) Aharonov-Bohm 효과: 솔레노이드 바깥의 전자가 코호몰로지를 통해 자기장의 영향을 받음.

9) Dirac 모노폴: 자기 모노폴의 존재성과 전기·자기 전하의 양자화 가 코호몰로지에서 자연스럽게 등장.

10) 위상 절연체와 Chern 수: NEGF·응집계 물리 의 위상학적 양들이 Berry 곡률의 적분 — 직접 코호몰로지 응용.

11) 외대수가 단순한 미분 도구가 아니라 공간의 모양 (위상) 을 측정하는 강력한 언어.

다음 §13 에서 Hodge 별표 $\star$ — 메트릭이 있을 때 $k$-form 과 $(n-k)$-form 의 자연스러운 대응 — 을 본다. 이 장에서 살짝 등장한 $\star$ 의 정확한 정의와 응용을 다룬다.
