mixed operator

제시된 혼합형 스펙트럼 전개에서 역연산이 각 항의 스칼라 역수로 직접 분배되는 이유는 직관적인 분배 법칙이 아니라, 이산 기저와 연속 기저 사이에 성립하는 상호 직교성(Mutual Orthogonality)에 기인합니다.임의의 연산자 $\hat{T}$ 에 대한 역연산자 $\hat{S}$ 가 존재한다면, 두 연산자의 곱은 필연적으로 항등 연산자 $\hat{I}$ 를 산출해야 합니다 ($\hat{T}\hat{S} = \hat{I}$). 이 대수적 공리를 바탕으로, 역연산의 형태가 성립함을 연역적으로 증명합니다.1. 작용소와 후보 역작용소의 정의원래의 작용소 $\hat{T} = (z\hat{I} - \hat{A})$ 와 스칼라 역수를 취하여 가정한 역작용소 $\hat{S} = R(z, \hat{A})$ 를 전개식 형태로 정의합니다.

$$\hat{T} = \sum_k (z - \lambda_k) |u_k\rangle \langle u^{d, k}| + \int_{\sigma_c} (z - \lambda(\nu)) |u(\nu)\rangle \langle u^d(\nu)| d\nu$$$$\hat{S} = \sum_m \frac{1}{z - \lambda_m} |u_m\rangle \langle u^{d, m}| + \int_{\sigma_c} \frac{1}{z - \lambda(\nu')} |u(\nu')\rangle \langle u^d(\nu')| d\nu'$$

두 연산자의 곱 $\hat{T}\hat{S}$ 를 계산할 때 분배 법칙에 의해 총 4개의 항이 발생합니다.2. 기저의 직교성 조건혼합형 정규 연산자의 완비적 기저는 다음의 3가지 직교성(Orthogonality) 조건을 만족합니다.이산-이산 직교성: $\langle u^{d, k} | u_m \rangle = \delta^k_m$ (크로네커 델타)연속-연속 직교성: $\langle u^d(\nu) | u(\nu') \rangle = \delta(\nu - \nu')$ (디랙 델타 함수)이산-연속 상호 직교성: 이산 고유 공간과 연속 고유 공간은 서로 완벽하게 독립적이므로, 내적은 항상 0입니다.

$$\langle u^{d, k} | u(\nu) \rangle = 0, \quad \langle u^d(\nu) | u_k \rangle = 0$$

3. 항등 연산자 도출 증명곱 $\hat{T}\hat{S}$ 의 4개 전개 항에 직교성 조건을 적용하여 계산합니다.(1) 교차 항 (Cross Terms)의 소거이산 기저와 연속 기저가 결합하는 두 교차 항은 상호 직교성 조건에 의해 대수적으로 소거됩니다.이산 $\times$ 연속: $\sum_k \int (z - \lambda_k) \frac{1}{z - \lambda(\nu')} |u_k\rangle \langle u^{d, k} | u(\nu') \rangle \langle u^d(\nu')| d\nu' = 0$연속 $\times$ 이산: $\int \sum_m (z - \lambda(\nu)) \frac{1}{z - \lambda_m} |u(\nu)\rangle \langle u^d(\nu) | u_m \rangle \langle u^{d, m}| d\nu = 0$(2) 이산-이산 항의 산출두 이산 급수의 곱은 크로네커 델타에 의해 하나의 급수로 축소됩니다.

$$\sum_k \sum_m (z - \lambda_k) \frac{1}{z - \lambda_m} |u_k\rangle \langle u^{d, k} | u_m \rangle \langle u^{d, m}|$$$$\sum_k \sum_m \frac{z - \lambda_k}{z - \lambda_m} \delta^k_m |u_k\rangle \langle u^{d, m}| = \sum_k \frac{z - \lambda_k}{z - \lambda_k} |u_k\rangle \langle u^{d, k}| = \sum_k |u_k\rangle \langle u^{d, k}|$$

(3) 연속-연속 항의 산출두 연속 적분의 곱은 디랙 델타 함수의 필터링 성질에 의해 하나의 적분으로 축소됩니다.

$$\int_{\sigma_c} \int_{\sigma_c} (z - \lambda(\nu)) \frac{1}{z - \lambda(\nu')} |u(\nu)\rangle \langle u^d(\nu) | u(\nu') \rangle \langle u^d(\nu')| d\nu d\nu'$$$$\int_{\sigma_c} \int_{\sigma_c} \frac{z - \lambda(\nu)}{z - \lambda(\nu')} \delta(\nu - \nu') |u(\nu)\rangle \langle u^d(\nu')| d\nu d\nu'$$

$\nu'$ 에 대한 적분을 수행하면 델타 함수에 의해 $\nu' = \nu$ 인 지점의 값만 추출됩니다.

$$\int_{\sigma_c} \frac{z - \lambda(\nu)}{z - \lambda(\nu)} |u(\nu)\rangle \langle u^d(\nu)| d\nu = \int_{\sigma_c} |u(\nu)\rangle \langle u^d(\nu)| d\nu$$

4. 결론살아남은 두 항을 합산하면 완비성 관계(Completeness relation)에 의해 공간의 항등 연산자 $\hat{I}$ 가 도출됩니다.

$$\hat{T}\hat{S} = \sum_k |u_k\rangle \langle u^{d, k}| + \int_{\sigma_c} |u(\nu)\rangle \langle u^d(\nu)| d\nu = \hat{I}$$

동일한 논리로 $\hat{S}\hat{T} = \hat{I}$ 역시 성립합니다. 따라서 각각의 기저에 결합된 스칼라 계수를 독립적으로 역수 취한 형태의 작용소 $\hat{S}$ 는 대수학적 불변량인 직교성에 의해 원래 작용소 $(z\hat{I} - \hat{A})$ 의 엄밀한 역작용소임이 논리적으로 증명됩니다. 무한 차원 공간에서 행렬 연산이 불가능함에도, 스펙트럼 분해가 적용된 상태에서는 각 성분의 역수를 취하는 것만으로 완벽한 역연산을 수행할 수 있습니다.
