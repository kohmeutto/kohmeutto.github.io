비컴팩트의 경우 — 지수의 곱 필요

1. 이 절의 동기

§12 에서 컴팩트 연결 리 군의 모든 원소가 단일 $\exp(X)$ 형태 임을 보았다. 비컴팩트 에서는 이것이 깨진다 — §12 §7 에서 $SL(2, \mathbb{R})$ 의 반례를 짧게 언급했다.

이 절에서 비컴팩트의 상황을 본격 분석 한다.

  • 왜 깨지는가 — 비컴팩트성이 불변 리만 메트릭 (Hopf-Rinow) 의 전제 를 깨뜨림
  • $SL(2, \mathbb{R})$ 의 명시적 반례 — $\text{tr}$ 분석으로 어떤 원소가 도달 안 되는지
  • 어떻게 도달하나 — 두 지수의 곱 $g = \exp(X_1) \exp(X_2)$ 면 충분
  • 극분해 (polar decomposition) — 비컴팩트 행렬군의 표준 매개변수화

이 절은 (i) 왜 비컴팩트에서 깨지는가, (ii) $SL(2, \mathbb{R})$ 트레이스 분석, (iii) 명시적 반례의 구체 검증, (iv) 지수의 곱이 항상 충분 (연결성), (v) 극분해, (vi) 응집계·NEGF 와의 연결 — 의 순서.

2. 왜 비컴팩트에서 깨지는가

§12 §3 의 증명 전략을 다시 보면 어디서 비컴팩트가 문제가 되는지 가 명확하다.

1) 증명에 필요했던 두 가지.

  • (i) 양변 불변 리만 메트릭 — Haar 측도로 평균해 얻음.
  • (ii) Hopf-Rinow — 모든 두 점이 측지선으로 연결.

2) (i) 의 문제 — Haar 측도 무한. 비컴팩트 리 군의 Haar 측도가 무한 (§2 §5 (3)). 따라서 평균 적분이 발산 할 수 있다. 양변 불변 리만 메트릭 구성이 일반적으로 안 됨 — 왼쪽 불변 만 가능.

3) (ii) 의 문제 — 측지적 비완비. 비컴팩트는 Hopf-Rinow 가 직접 적용 안 됨. 왼쪽 불변 메트릭만으로는 측지적 완비가 보장되지 않음.

4) 결과 — 단일 지수가 모든 원소를 도달 못 함. 항등원에서 측지선으로 도달 못 하는 원소 가 존재 가능. 그 원소가 $\exp(\mathfrak{g})$ 이미지에 없음.

5) 그러나 비컴팩트도 연결이면 도달 가능 — 지수의 곱으로. 연결 리 군의 임의 원소는 항등원 근방의 원소들을 곱해서 도달 가능 — 일반적 사실. 항등원 근방은 $\exp$ 의 이미지 안 (§7 §6 의 미분 동형사상). 따라서 유한 개 지수의 곱 이 모든 원소를 표현.

결론. 비컴팩트 연결 리 군에서 — 단일 지수는 비전사, 지수의 곱은 전사.

3. $SL(2, \mathbb{R})$ — 트레이스 분석

비컴팩트의 표준 반례 $SL(2, \mathbb{R})$ 를 본격 분석.

1) $SL(2, \mathbb{R})$ 와 $\mathfrak{sl}(2, \mathbb{R})$ 재확인. $\det = 1$ 인 $2 \times 2$ 실 행렬, 3차원 비컴팩트 연결 리 군. 리 대수는 트레이스 0 $2 \times 2$ 실 행렬, 3차원.

2) 케일리-해밀턴 정리 적용. $X \in \mathfrak{sl}(2, \mathbb{R})$ ($\text{tr}(X) = 0$) 의 특성 다항식

$$\lambda^2 - \text{tr}(X) \lambda + \det(X) = \lambda^2 + \det(X) = 0$$

(트레이스 $0$ 적용.) 케일리-해밀턴 — $X^2 + \det(X) I = 0$, 즉

$$X^2 = -\det(X) \cdot I$$

3) 세 경우의 분기 — $\det(X)$ 의 부호로.

경우 (a) $\det(X) = d > 0$ (타원형, elliptic). $X^2 = -d \cdot I$. $X$ 의 고유값이 $\pm i\sqrt{d}$ (순허수).

$$\exp(X) = \sum_n \frac{X^n}{n!} = \cos(\sqrt{d}) \cdot I + \frac{\sin(\sqrt{d})}{\sqrt{d}} X$$

(코사인은 짝수 항, 사인은 홀수 항. $X^{2k} = (-d)^k I$, $X^{2k+1} = (-d)^k X$.)

$$\text{tr}(\exp X) = 2 \cos\sqrt{d} \in [-2, 2]$$

경우 (b) $\det(X) = 0$ (포물형, parabolic, nilpotent). $X^2 = 0$. $X$ 의 고유값 모두 $0$.

$$\exp(X) = I + X + 0 + 0 + \cdots = I + X$$$$\text{tr}(\exp X) = \text{tr}(I) + \text{tr}(X) = 2 + 0 = 2$$

경우 (c) $\det(X) = -d < 0$ (쌍곡형, hyperbolic). $X^2 = d \cdot I$. $X$ 의 고유값 $\pm\sqrt{d}$ (실수).

$$\exp(X) = \cosh(\sqrt{d}) \cdot I + \frac{\sinh(\sqrt{d})}{\sqrt{d}} X$$

(쌍곡 함수.)

$$\text{tr}(\exp X) = 2 \cosh\sqrt{d} \ge 2$$

4) 세 경우의 트레이스 범위 종합.

경우 $\det(X)$ $\text{tr}(\exp X)$
타원 $> 0$ $[-2, 2]$
포물 $= 0$ $= 2$
쌍곡 $< 0$ $\ge 2$

5) 결론 — $\text{tr}(\exp X) \ge -2$ 항상. 모든 $X \in \mathfrak{sl}(2, \mathbb{R})$ 에 대해 $\text{tr}(\exp X) \ge -2$.

추가로 — $\text{tr}(\exp X) = -2$ 는 타원 + $\cos\sqrt{d} = -1$ + $\sin\sqrt{d} = 0$ 시. 즉 $\sqrt{d} = \pi$, 그리고 $\sin\sqrt{d} = 0$ 이라 2차 항이 $0$ — $\exp(X) = -I$.

→ $\text{tr} = -2$ 인 유일한 $\exp$ 이미지가 $-I$.

4. 명시적 반례 — $M = \begin{pmatrix} -1 & 1 \\ 0 & -1 \end{pmatrix}$

§12 §7 (2) 에서 미리 언급한 반례를 본격 검증.

1) $M$ 의 성질.

  • $\det M = (-1)(-1) - 0 \cdot 1 = 1$ → $M \in SL(2, \mathbb{R})$ ✓
  • $\text{tr}(M) = -1 + (-1) = -2$
  • $M \neq -I$ (왜냐하면 $M_{12} = 1 \neq 0$)

2) $M = \exp(X)$ 가능한가. §3 (5) 의 결과 — $\text{tr} = -2$ 이려면 반드시 $\exp(X) = -I$. 그러나 $M \neq -I$.

→ $M \notin \exp(\mathfrak{sl}(2, \mathbb{R}))$. 단일 지수로 도달 못 함. ∎

3) 기하학적 해석 — $M$ 의 의미. $M$ 은 대각 $-1$ + 비대각 $1$ — $-I$ 의 가까운 변형. 비대각 $1$ 이 nilpotent 보정.

$M = -I + N$ where $N = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$ (rank 1 nilpotent). 또는 $M = -(I - N)$. "$-I$ 와 nilpotent 의 곱" 형태.

4) 왜 $\exp$ 로 도달 못 하나 — 직관. $\exp(\mathfrak{sl}(2, \mathbb{R}))$ 의 이미지가 $SL(2, \mathbb{R})$ 의 진부분집합. $M$ 같은 "$-I$ 근방의 nilpotent 보정" 이 이 진부분집합에 안 들어감.

5) 지수의 곱으로 도달 가능 — 다음 §5 에서.

5. 지수의 곱으로 도달 — $M = \exp(X_1) \exp(X_2)$

$M$ 을 두 지수의 곱 으로 표현해본다.

1) 분해. $M = (-I) \cdot (I - N)$ where $N = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$.

확인 — $(-I)(I - N) = -I + N$. 그런데 $M = -I + N$? — 직접 계산 —

$M = \begin{pmatrix} -1 & 1 \\ 0 & -1 \end{pmatrix}$, $-I + N = \begin{pmatrix} -1 & 0 \\ 0 & -1 \end{pmatrix} + \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} -1 & 1 \\ 0 & -1 \end{pmatrix} = M$. ✓

2) 각 인자가 지수 형태인가.

$-I = \exp(X_1)$ — $X_1 \in \mathfrak{sl}(2, \mathbb{R})$ 으로 잡을 수 있는가. §3 (5) — $\exp(X) = -I$ 의 유일한 경우는 $\det X = \pi^2$ (양수), $X^2 = -\pi^2 I$. 예 — $X_1 = \pi \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix} = \pi J$ ($J$ 는 §6 §10 의).

확인 — $X_1^2 = \pi^2 J^2 = -\pi^2 I$, $\exp(X_1) = \cos\pi \cdot I + \sin\pi/\pi \cdot X_1 = -I + 0 = -I$. ✓

$I - N = ?$ — $M$ 의 결과에서 $(-I)$ 를 빼낸 나머지. 이를 $\exp(X_2)$ 로 표현?

$X_2 = -N = \begin{pmatrix} 0 & -1 \\ 0 & 0 \end{pmatrix}$. nilpotent, $X_2^2 = 0$.

$\exp(X_2) = I + X_2 = \begin{pmatrix} 1 & -1 \\ 0 & 1 \end{pmatrix} \neq I - N$. 부호 문제.

다시 — $X_2 = N$ 으로 하면 $\exp(N) = I + N$. $M = (-I)(I + N)$? — 확인 — $(-I)(I + N) = -I - N \neq M$. 음.

다시 — $M = -I + N = (-I)(I - N)$ 가 맞고, $I - N = \exp(-N) = \exp\begin{pmatrix} 0 & -1 \\ 0 & 0 \end{pmatrix}$.

$\exp(-N) = I + (-N) + 0 + \cdots = I - N$. ✓

→ $M = \exp(\pi J) \cdot \exp(-N)$. 두 지수의 곱 으로 도달. ✓

3) 물리적 의미. $M$ 이 $\pi$ 회전 ($\exp(\pi J) = -I$) + 전단 변환 (shear, $\exp(-N) = I - N$) 의 합성. 두 변환이 각각 1-매개변수 부분군 (각각 $SO(2)$ 와 상삼각 unipotent 부분군) 이지만, 그 합성이 단일 1-매개변수 부분군이 아님 — 따라서 단일 $\exp$ 로 표현 안 됨.

4) 일반 정리.

정리. 비컴팩트 연결 리 군 $G$ 에서, 모든 $g \in G$ 가 유한 개 지수의 곱 으로 표현 가능 —

$$g = \exp(X_1) \exp(X_2) \cdots \exp(X_k), \quad X_i \in \mathfrak{g}$$

증명 (스케치) — 항등원 근방의 모든 원소가 $\exp$ 의 이미지 (지수 사상의 국소 미분 동형사상, §7 §6). 연결 리 군은 항등원 근방 원소들의 곱으로 전체 도달 — 토폴로지 사실. 따라서 임의 $g$ 가 항등원 근방 원소들 $g_i = \exp(X_i)$ 의 곱.

5) 결과 — $SL(2, \mathbb{R})$ 의 경우. 모든 $M \in SL(2, \mathbb{R})$ 가 두 개 (또는 그 이상) 지수의 곱으로 표현. 단일 지수만으로는 부족 — 적어도 두 개 필요한 원소들이 존재.

6. 극분해 — 비컴팩트의 표준 매개변수화

비컴팩트 행렬군의 표준 매개변수화는 극분해 (polar decomposition). 위 §5 의 $\exp(X_1) \exp(X_2)$ 구조를 체계화.

1) 행렬의 극분해. $\det \neq 0$ 행렬 $A \in GL(N, \mathbb{F})$ 가 유일하게 분해

$$A = U \cdot P$$

where $U$ 가 유니타리 (또는 직교), $P$ 가 양의 정부호 에르미트 (또는 양의 정부호 대칭). 복소수의 극형식 $z = e^{i\theta} \cdot r$ 의 행렬 버전.

2) $P$ 의 지수 표현. $P$ 가 양의 정부호 에르미트 이라 유일한 에르미트 $H$ 에 대해 $P = \exp(H)$. ($H = \log P$ 가 잘 정의.)

3) 행렬군 적용. $G$ 가 $GL(N, \mathbb{F})$ 의 부분군이면, $G$ 의 원소도 $G$ 안에서 극분해 가능 (적절한 조건 아래).

4) $SL(2, \mathbb{R})$ 의 극분해.

$$SL(2, \mathbb{R}) = SO(2) \cdot \exp(\mathfrak{p})$$

where $\mathfrak{p}$ = 대칭 트레이스 0 행렬 의 공간 (2차원). 즉

$$M = R(\theta) \cdot \exp(P)$$

with $R(\theta) \in SO(2)$ (컴팩트 부분) 과 $\exp(P)$ ($P$ 대칭 트레이스 0).

매개변수 자유도 — $\theta$ 1개 (SO(2)) + $P$ 2개 ($\mathfrak{p}$ 차원) = 3개. $\dim SL(2, \mathbb{R}) = 3$ 과 일치. ✓

5) 카르탕 분해 (Cartan decomposition). 위 극분해의 리 대수 차원 일반화

$$\mathfrak{g} = \mathfrak{k} \oplus \mathfrak{p}$$

where $\mathfrak{k}$ 가 컴팩트 부분 대수 (예 — $\mathfrak{so}(2) \subset \mathfrak{sl}(2, \mathbb{R})$), $\mathfrak{p}$ 가 비컴팩트 보충 (대칭 트레이스 0). 카르탕 분해가 비컴팩트 반단순 리 군 분석의 표준 도구 — 응집계의 대칭 분류, 일반 상대성 이론의 변환군 등에 등장.

7. 다른 비컴팩트 예 — Lorentz 군

비컴팩트 연결 리 군의 또 다른 표본 — Lorentz 군의 항등원 성분 $SO^+(1, 3)$.

1) $SO^+(1, 3)$ 재확인 (§2 §4 (4)). $4 \times 4$ 실 행렬, 메트릭 $\eta = \text{diag}(+,-,-,-)$ 보존, $\det = 1$, $\Lambda^0{}_0 \ge 1$. 6차원 비컴팩트 연결.

2) 카르탕 분해. $SO^+(1, 3) = SO(3) \cdot (\text{boost})$

  • $SO(3)$ = 공간 회전 (컴팩트 부분, 3차원)
  • boost (부스트) = 시간-공간 회전 — 쌍곡선 회전, 3차원 비컴팩트

총 6차원 ✓.

3) $\exp$ 의 한계. $SO^+(1, 3)$ 의 일반 원소도 단일 $\exp$ 로 도달 안 되는 경우 존재 ($SL(2, \mathbb{R})$ 와 비슷한 분석). 회전과 부스트의 결합 이 단일 무한소 변환 으로 안 됨.

4) 극분해. 임의 $\Lambda \in SO^+(1, 3)$ 가

$$\Lambda = R \cdot B$$

where $R$ 가 공간 회전, $B$ 가 boost. 두 매개변수가 독립.

5) 응집계 물리에서의 의미. 비상대론적 응집계에서는 직접 안 등장하지만, Galileo 군, Poincaré 군의 부분 구조 가 비슷한 분해. 시간-공간 좌표 변환의 본질 이 카르탕 분해로 드러남.

8. 응집계·NEGF 와의 연결

비컴팩트 리 군의 등장 — 본 시리즈 사용자 (NEGF·SBD 연구자) 의 관심.

1) Bogoliubov-de Gennes (BdG) 변환. 초전도체 평균장 해밀토니안의 대각화에 사용. BdG 변환이 준입자 unitary 와 Nambu rotation 의 결합으로 — $Sp(2N, \mathbb{R})$ 의 표현. 비컴팩트 심플렉틱.

2) 비에르미트 양자역학. 비에르미트 해밀토니안 (PT-대칭 시스템, 게인-로스 격자 등) 의 시간 진화가 $GL$ 의 비유니타리 부분군. 단일 시간 진화 연산자 = $\exp(-iHt)$ 가 비유니타리 → 비컴팩트 군에 속함.

3) NEGF 자기에너지 $\Sigma = \Delta - i\eta_0$. 비에르미트 보정 — 환경과의 결합으로 인한 유효 비에르미트. 자기에너지의 행렬 구조가 $GL$ 안의 곡선 으로 표현됨, 단순 $\exp$ 로는 일반적으로 표현 안 됨. 카르탕 분해 비슷한 구조 활용 가능.

4) 전송 행렬 (Transfer matrix). 1D 전도 채널의 산란 행렬, 전송 행렬 이 $SU(N, N)$ 같은 비컴팩트 의사 유니타리군 에 속함. 극분해로 유니타리 회전 + 비컴팩트 boost (= 전송 채널의 투과/반사 비) 로 분해.

5) 결과 — 비컴팩트 리 군 이론은 응집계의 비에르미트·비평형 시스템 분석에 필수. 단순 $\exp$ 가 안 통하므로 극분해, 카르탕 분해, 이와사와 분해 등 더 깊은 도구가 필요.

표준 분해 최대 토러스 + Weyl 카르탕 분해 ($\mathfrak{k} \oplus \mathfrak{p}$)
예 $U(N), SU(N), SO(N)$ $GL, SL, Sp(\cdot, \mathbb{R}), SO(1,n)$

10. 이 절을 닫으며

이 절에서 점검한 것.

(1) 비컴팩트에서 $\exp$ 전사가 깨짐 — Haar 측도 무한, Hopf-Rinow 안 됨. 단일 $\exp$ 가 모든 원소를 도달 못 함.

(2) $SL(2, \mathbb{R})$ 트레이스 분석 — 케일리-해밀턴 + 세 경우 (타원·포물·쌍곡) 분기. $\text{tr}(\exp X) \ge -2$ 항상, $= -2$ 만 가능한 $\exp$ 이미지는 $-I$.

(3) 명시적 반례 — $M = \begin{pmatrix} -1 & 1 \\ 0 & -1 \end{pmatrix}$, $\text{tr} = -2$ 이나 $\neq -I$ 이므로 $\exp$ 이미지에 없음.

(4) 지수의 곱으로 도달 가능 — $M = \exp(\pi J) \cdot \exp(-N)$. 일반적으로 연결 리 군은 유한 개 지수의 곱으로 모든 원소 표현 (위상적 사실).

(5) 극분해 — 비컴팩트 행렬군의 표준 매개변수화. $A = U \cdot P$ ($U$ 유니타리, $P$ 양의 정부호). $SL(2, \mathbb{R}) = SO(2) \cdot \exp(\mathfrak{p})$.

(6) 카르탕 분해 — 리 대수 차원 $\mathfrak{g} = \mathfrak{k} \oplus \mathfrak{p}$. 컴팩트 + 비컴팩트 부분의 직합. 비컴팩트 반단순 리 군 분석의 표준 도구.

(7) 다른 비컴팩트 예 — $SO^+(1, 3)$ (Lorentz 군), $Sp(2N, \mathbb{R})$, $GL(N, \mathbb{R})$.

(8) 응집계·NEGF 와의 연결 — BdG 변환, 비에르미트 해밀토니안, NEGF 자기에너지, 전송 행렬 등에서 비컴팩트 리 군이 자연 등장.

다음 §14 에서 비연결의 경우 — $O(N)$ 같은 비연결 리 군에서 항등원 성분 외 다른 성분 도달 방법 (이산 변환 추가) — 을 다룬다. 이로써 4부 (지수 사상의 한계) 가 완성된다.
