1. 무슨 문제를 푸는가

정상 상태의 준선형 타원형 방정식입니다.

$$\nabla\cdot\bigl(p(u,x,y)\,\nabla u\bigr) + q(u,x,y) = 0$$
기호 뜻 예
$u$ 구하려는 값 온도, 전위
$p$ 확산 계수 열전도율, 유전율
$q$ 소스 발열, 전하

$q$ 는 소스 그 자체입니다. 발열이면 양수를 그대로 넣습니다. 열전도에서 흔히 쓰는 표기와 같습니다.

$$\nabla\cdot(\kappa\nabla T) + Q = 0 \qquad (Q > 0 \text{ 이 발열})$$

게재된 논문은 $\nabla\cdot(p\nabla u) = q$ 로 잡아 $q$ 의 부호가 반대입니다. 그쪽 식을 함께 볼 때는 $q$ 를 뒤집어 읽어야 합니다.

두 가지가 어렵게 만듭니다.

무엇 왜 어려운가
1 $p$ 가 $u$ 에 의존한다 (준선형) 자코비안이 비대칭이 된다
2 $p$ 가 물질 경계에서 불연속이다 계면에서 계수가 몇 자릿수 뛴다

$p = 148\,u^{-1.3}$ 인 실리콘과 $p = 1.4$ 인 산화막이 맞닿는 FinFET 자기발열이 그 예입니다. 온도가 오르면 열전도가 떨어져 발열이 더 심해집니다.

시간 항이 필요할 때도 있습니다.

$$c(x,y)\,\frac{\partial u}{\partial t} = \nabla\cdot(p\nabla u) + q$$

정상해가 아예 없는 구성이 있습니다. 소스가 임계를 넘으면 열폭주가 일어나 정상 문제로는 못 풉니다. 그 경우 시간을 전진시켜야 합니다.

$\iota$, $\upsilon$, $\pi$, $\mu$, $\phi$, $\psi$, $\Lambda$, $\Sigma$, $\Theta$, $\Omega$, $\Upsilon$

$i$ 나 $v$ 와 헷갈리거나, 다른 뜻으로 이미 굳어 있는 글자입니다.

3. 왜 전처리가 필요한가

유한체적법으로 이산화하면 자코비안 $\hat J$ 가 나옵니다. 이것이 비대칭입니다.

$$\hat J_{ij} \ne \hat J_{ji}$$

비대칭이면 켤레기울기법을 못 쓰고, GMRES 를 써도 수렴이 느립니다.

대칭·반대칭으로 가릅니다

$$\hat J = \underbrace{\tfrac{1}{2}(\hat J + \hat J^{\mathsf T})}_{\text{대칭}} + \underbrace{\tfrac{1}{2}(\hat J - \hat J^{\mathsf T})}_{\text{반대칭}}$$

대칭부만 남기면 풀기 쉽습니다. 문제는 반대칭부를 버려도 되는가 입니다.

$$\rho_{\mathrm{int}} = \sup_{\mathbf w \ne 0} \frac{\lvert\mathbf w^{*}A\mathbf w\rvert}{\mathbf w^{*}S\mathbf w}$$

이 값이 1보다 작으면 대칭부만으로 만든 전처리기가 잘 듣습니다. $\rho_{\mathrm{int}}$ 를 실제로 재고, 그것으로 감쇠와 허용오차를 정합니다.

유도는 60_유도_상한.md.

노드마다 배율을 곱해 격자 탓을 먼저 걷어냅니다

비대칭에는 두 가지가 섞여 있습니다.

섞인 것 왜 생기나
격자 탓 노드마다 맡은 넓이가 달라서
물리 탓 $p$ 가 $u$ 에 따라 달라져서

앞의 것은 걷어낼 수 있습니다. 노드마다 배율 $\hat c_i$ 를 하나씩 곱하면 됩니다.

$$\hat C = \mathrm{diag}(\hat c_i)$$

그 배율은 이렇게 찾습니다. 간선마다 양쪽에서 본 두 성분의 비를 로그로 재고, 그것이 노드마다 정해진 어떤 수의 차이로 얼마나 설명되는지를 봅니다. 가장 잘 설명하는 값을 최소제곱으로 구하면 그것이 $\hat c$ 입니다.

설명되지 않고 남는 것은 그대로 둡니다.

$$\hat C\hat J = \underbrace{\tilde J_{\text{pure}}}_{\text{대칭}} + \underbrace{\tilde A_{\text{int}}}_{\text{반대칭}}$$

남은 $\tilde A_{\text{int}}$ 안에 해가 어느 쪽으로 가야 하는지가 들어 있습니다. 온도가 오르면 열전도가 떨어지는 물질에서 뜨거운 쪽과 찬 쪽은 서로 대칭이 아닙니다. 그 방향까지 지우면 푸는 문제가 달라집니다.

$$\text{걷어낼 수 있는 만큼만 걷어내고, 남은 것은 얼마나 큰지 재서 다룹니다}$$

되풀이가 네 겹이다

겹 어디에 있나 무엇을 되풀이하나 몇 번까지
첫째 (마이크로) 감춘 solve 뉴턴 걸음을 밟는다 MaxMicro
둘째 (매크로) 감춘 solve 뉴턴이 끝나면 격자를 손볼지 보고 다시 뉴턴으로 MaxMacro
셋째 solveSteady 다 푼 해를 보고 노드 수가 모자라면 격자를 새로 만들어 다시 푼다 HAdaptOpt.MaxHRefine
넷째 solveTransient 한 시각을 다 풀면 다음 시각으로 MaxSteps

앞의 둘이 감춘 solve 안에 있습니다. 마이크로가 수렴하고 격자가 더 안 움직이면 그 안에서 끝납니다.

셋째와 넷째는 나란한 층이고 서로를 안 부릅니다. solveTransient 은 solveSteady 를 거치지 않고 자기 안에서 격자를 손봅니다. 시각마다 지켜야 할 순서가 있기 때문입니다.

격자를 늘린다  ->  해를 옮겨 담는다  ->  시간 간격을 잰다  ->  푼다

각 겹에서 무엇을 할지는 옵션이 정합니다.

겹 옵션 참이면
둘째 sv.UseRAdapt 노드를 급한 자리로 옮긴다. 노드 수는 그대로다
셋째 sv.UseHAdapt 노드 수가 모자라면 늘려서 다시 푼다

둘 다 기본이 켬입니다. 아무것도 안 정해도 알맞은 격자를 찾습니다.

8. 가장 짧은 사용 예

% 1. 영역
dom = ContinuousDomain2D('Bounds', [0 1 0 1], 'CoordSystem', Cartesian2D());
idL = dom.addRegion('Name', "Left",  'Type', "rectangle", 'Params', [0 0.5 0 1]);
idR = dom.addRegion('Name', "Right", 'Type', "rectangle", 'Params', [0.5 1 0 1]);

% 2. 물성과 경계조건
pm = PhysicsManager2D('Domain', dom);
pm.setEquation(idL, 'P', "1.0",          'Q', "1.0");
pm.setEquation(idR, 'P', "0.1*exp(2*u)", 'Q', "1.0");
pm.setEquation("Bottom", 'U', 0.0);                              % Dirichlet
pm.setEquation("Top", 'Alpha', "0.0", 'Beta', "1.0", 'Gamma', "0.0");  % Neumann
pm.compile();

% 3. 격자
mm = MeshManager2D('Domain', dom);
mm.generateMesh('Nx', 64, 'Ny', 64, 'InterfaceLevel', 2);
mm.updateMetrics(pm);

% 4. 풀이
sv = ResidueSolverNR2D('MeshM', mm, 'PhysM', pm);
[U, r_norm, steady_info] = sv.solveSteady();

위의 solveSteady 는 기본으로 노드를 옮기고 늘립니다. $N_x$ 를 정해 놓고 재려면 h-정제를 끕니다.

sv.UseHAdapt = false;
[U, r_norm] = sv.solveSteady();

시간을 전진시키려면 이렇게 합니다.

[U, transient_info] = sv.solveTransient('TEnd', 10, 'DtPhys', 0.1);
