4. 수치적 실험 및 검증

최근 수치해석 분야에서는 JAX나 PyTorch와 같은 자동 미분(automatic differentiation) 기반 프레임워크를 활용하여 연산 효율과 구현 편의를 도모하는 방식이 활용되고 있다. 그러나 본 연구에서 제안하는 대수적 보정 프레임워크는 비선형 연산자의 조립 단계부터 반대칭 성분 추출에 이르는 명시적인 대수적 제어(algebraic control) 과정을 포함한다. 이에 따라 알고리즘의 제어 계층(control layer)과 표준 선형대수 연산 계층(linear algebra layer)을 분리하여 MATLAB (64-bit double precision) 환경에서 구현하였으며, 범용 자동 미분 라이브러리나 상용 PDE 패키지는 사용하지 않았다. 프레임워크를 구성하는 세부 알고리즘 및 기하-대수적 제어 절차는 다음과 같다.

첫째, 3.1절에서 도출된 이산 공간 국소 비대칭 지표 $S_{kj}$를 텐션 모델로 변환하여 $r$-적응형(r-adaptive) 격자 이동을 제어한다. 오차가 발생하는 구역의 텐션을 가중치 행렬 $\hat{W}$에 반영하고, 이를 바탕으로 그래프 라플라시안(Graph Laplacian) 시스템을 구성하여 조화 사상(harmonic mapping) 방정식을 산출한다. 이 과정에서 계면 인접 노드의 자율 스내핑(auto-snapping)을 적용하여, 물성 계면이 단일 요소(element) 내부를 관통할 때 발생하는 조화 평균 역설(harmonic mean paradox) 및 대수 왜곡을 방지한다. 이산 노드가 물리적 계면으로부터 요소 길이의 절반 미만인 특정 거리 이내로 접근할 경우 해당 노드의 좌표를 계면 위치로 조정한다. 이를 통해 요소 내부의 킹크(kink) 발생과 초기 격자망이 계면과 일치하여 오차가 상쇄되는 기하학적 배열(lucky alignment)을 배제한다.

둘째, 격자 재배치 과정에서 발생하는 기하학적 텐션에 의한 비선형 잔여항(residual) 증가 현상을 제어하기 위해, 위상 동결 기제인 ‘골든 상태 롤백(Golden State Rollback)‘을 적용하였다. 매 반복 단계에서 잔여항의 노름(norm)을 계산하고, 최소 오차를 나타내는 기하 좌표와 상태 변수를 최적 상태로 저장한다. 격자 이동 후 오차가 증가할 경우 시스템을 이전의 최적 상태로 복구하고 격자의 위상 변형을 동결(mesh freezing)하여 점근적 수렴성을 유도한다. 비선형 잔차($R$) 및 프레셰 도함수(Fréchet derivative, $\hat{J}$)의 조립은 해석적(analytical) 미분 법칙을 기반으로 한다. 공간 적분은 차원별 이산화 특성에 따라 1차원 도메인에서는 다점 가우스-르장드르 구적법(multi-point Gauss-Legendre quadrature)을, 2차원 비구조적 격자계에서는 간선 중점 평가(edge-midpoint evaluation)를 적용하였다.

셋째, 3.2절의 수반 일관성(adjoint consistency) 조건을 만족하기 위해, 내부 레지듀를 최소화하는 대각 정규화 행렬 $\hat{C}$를 최소자승법(least squares)으로 산출한다. 또한 디리클레 경계 조건이 내부 노드의 연산자 구조에 미치는 영향을 제외하기 위해, 사영 연산자(projection operator) 형태의 마스크 행렬 $\hat{M}_s$를 적용한다. 이를 바탕으로 2.4절의 벌크-경계 소산 정리를 적용하여, 시스템의 비대칭성으로부터 내부 스퓨리어스 반대칭 성분($\hat{A}_{int}$)을 분리한다. 추출된 성분을 원시 자코비안에서 감산하여 보정된 자코비안($\hat{J}_{pure}$)을 구성한다.

선형 시스템의 풀이 과정에서는 표준적인 행렬 연산 알고리즘을 사용하였다. 행렬의 메모리 구조화에는 CSC(Compressed Sparse Column) 희소 행렬 포맷을 활용하였으며, 선형 연립방정식($\hat{J}_{pure} \delta u = -R$)의 직접 해법에는 내장 솔버(UMFPACK 기반 역슬래시 연산자)를 적용하였다. 자코비안의 조건수(condition number) 산출에는 1-노름 기반의 조건수 추정 함수(condest)를 이용하였다.

4.1 1차원 특이 섭동 시스템의 대수적 무결성 검증

무차원 유클리드 1차원 도메인 $\Omega = [0, 1]$ 상에서, 상태 종속적 비선형 확산 계수 $P(u, x)$를 가지는 강타원형(strongly elliptic) 보존 방정식은 다음과 같이 정의된다.

$$ \frac{d}{dx} \left( P(u, x) \frac{du}{dx} \right) = Q(x) \quad \text{in } \Omega $$

시스템의 수치적 강성(stiffness)을 평가하기 위해, 도메인을 계면 $x_{int} = 0.2$ 위치를 기준으로 좌측 매질과 우측 매질로 분할하며, 확산 계수 $P(u, x)$에 불연속성을 부여한다. 우측 매질에는 투과율 단차 계수 $\sigma$가 적용된다.

$$ P(u, x) = \begin{cases} 1 + u^2 & \text{if } x \le x_{int} \\ \sigma (1 + u^2) & \text{if } x > x_{int} \end{cases} $$

해석적 정해 $u_{exact}(x)$는 각속도 $k = 2\pi f$를 가지는 정현파(sinusoidal wave)를 기저 함수로 하여 다음과 같이 조립된다.

$$ u_{exact}(x) = \begin{cases} \sin(k x) + C_L x & \text{if } x \le x_{int} \\ \sin(k x) + C_R (x - 1) + U_{end} & \text{if } x > x_{int} \end{cases} $$

여기서 1차 계수 $C_L$과 $C_R$은 계면 $x_{int}$에서의 전위 연속성($u_L = u_R$)과 비선형 유량 연속성($P_L u_L' = P_R u_R'$)을 만족하도록 역산된 고정 상수이며, 우측 종단($x=1$)의 목표 전위는 $U_{end} = 1.0$으로 설정된다.

알고리즘의 대수적 제어 능력을 검증하기 위해 두 가지 수치적 제약(numerical stressor)을 통제 변수로 고정한다. 첫째, 매질의 계면 위치를 도메인 중앙이 아닌 $x_{int} = 0.2$에 배치하여, 균일 격자 분할 시 계면이 특정 노드와 일치함으로써 보간 오차가 소거되는 기하학적 우연성(lucky alignment)을 배제한다. 둘째, 도메인 우측 종단($x=1$)에 비대칭 로빈 혼합 경계 조건($\alpha=2.0, \beta=1.0$, $\alpha u + \beta J = \gamma$)을 적용한다. 이는 자코비안 행렬 구축 시 대각 지배성(diagonal dominance)을 약화시키고 대수적 비대칭성을 유도한다.

4.2 2차원 특이 섭동 시스템의 대수적 무결성 검증

1차원 공간에서의 검증을 확장하여, 본 절에서는 교차 미분항(cross-derivative)이 존재하고 기하학적 자유도가 높은 2차원 비구조적 삼각 격자계(unstructured triangular mesh)를 대상으로 2장과 3장에서 도출된 대수적 정화 프레임워크의 타당성을 검증한다. 2차원 도메인 $\Omega = [0, 1] \times [0, 1]$ 상에서 정의되는 비선형 타원형 편미분 방정식은 다음과 같다.

$$ \nabla \cdot \left( P(u) \nabla u \right) = Q(x, y) \quad \text{in } \Omega $$

수치적 강성을 제어하기 위해 지수 함수 형태의 비선형 확산 계수 $P(u) = \exp(k_{nl} u)$를 도입한다. 도메인은 수직 계면 $x_{int} = 0.7$을 기준으로 좌측 매질과 우측 매질로 분할되며, 우측 매질에는 투과율 계수 $\sigma$가 적용되어 큰 폭의 물성 불연속성을 유도한다. 조립 해법(MMS)의 해석적 정해로는 다음과 같은 지수 감쇠 모델을 적용하였다.

$$ u_{exact}(x, y) = \begin{cases} U_0 \exp(-\alpha_L x) \cos(\pi y) & \text{if } x \le x_{int} \\ U_0 \exp(-\alpha_L x_{int}) \exp(-\alpha_R (x - x_{int})) \cos(\pi y) & \text{if } x > x_{int} \end{cases} $$

기준 진폭을 $U_0 = 1.0$, 좌측 매질의 감쇠율을 $\alpha_L = 2.0$으로 상정할 때, 우측 매질의 감쇠율 $\alpha_R$은 계면에서의 비선형 유량 보존 법칙($P_L \nabla u_L \cdot \mathbf{n} = P_R \nabla u_R \cdot \mathbf{n}$)에 의해 결정된다. 연속 조건($u_L = u_R$)에 의해 양변의 비선형 항이 소거됨으로써, 우측 감쇠율은 투과율 단차에 반비례하는 $\alpha_R = \alpha_L / \sigma$ 이다.

1) Case A: 비선형 강도 스윕에 따른 프레셰 도함수 비대칭성 제어 및 대수적 정화 검증 (Varying $k_{nl}$)

첫 번째 시나리오는 통제 조건($\sigma=10^{-2}, k_{nl}=2.0$) 하에서 공간 분해능 $N_x$를 8에서 64로 확장하며, 비정합 격자망에서 프레임워크가 점근적 수렴성을 유지하는지 확인한다.

표 4.4의 스펙트럼 지표를 분석하면 $N_x=64$ 구간에서 원시 비대칭성(Raw Asym)이 $644.0$ 규모로 증가하는 현상이 관측된다. 이는 기하학적 보정만으로는 완전히 제거하기 어려운 2차원 비정합 격자망 특유의 이산 교환자(discrete commutator) 응력에 기인한다. 그러나 직교 여공간 사영을 통한 대수적 정화기가 시스템의 수치 소산을 능동적으로 제어한 결과, 잔류 비대칭성은 $2.84 \times 10^{-2}$ 수준으로 감소하였으며, 이는 원시 시스템 대비 $5.0$배의 조건수 안정화로 이어졌다. 결과적으로 보정된 시스템은 그림 4.5의 로그 스케일 그래프에서 오차의 정체나 진동 없이 이론적인 $\mathcal{O}(h^2)$ 수준의 점근적 하강 궤도를 유지하며 $L_2$ 오차를 $2.56 \times 10^{-3}$으로 수렴시켰다.

2) Case B: 이산화 한계 공간에서의 대수적 생존성 평가 (Varying $\sigma$)

두 번째 시나리오는 $k_{nl}=1.0$, $N_x=32$ 조건 하에서 투과율 단차 $\sigma$를 $1.0$에서 $10^{-3}$까지 점진적으로 축소시킨다. 해당 실험은 계면의 미분 불연속성이 격자의 기하학적 해상도 한계를 초과했을 때 유발되는 기하학적 위상 변형과 시스템의 대수적 안정성을 분석한다.

[Figure 4.6 위치: 투과율 단차 $\sigma$ 축소에 따른 2D 비구조적 격자망의 국소 밀집(Mesh Deformation) 도식 삽입]

[Table 4.5 위치: 투과율 단차 $\sigma$ 축소에 따른 극한 이산화 한계 생존성 지표 표 삽입]

$\sigma=10^{-3}$일 때 우측 매질은 $\alpha_R = 2000$ 수준의 감쇠를 겪는다. 그림 4.6의 기하학적 궤적에서 확인되듯, 계면($x_{int}=0.7$)에서 발생하는 극단적인 미분 불연속성(kink)에 대응하기 위해 $r$-적응형 모듈은 해당 구역으로 비구조적 격자의 연결망을 조밀하게 밀집시킨다. 표 4.5의 지표를 분석하면, 이러한 자율적 위상 적응에도 불구하고 $N_x=32$ 격자망의 근본적인 해상도 한계로 인해 절단 오차(truncation error)가 잔존하여 $Cond(J) \approx 10^6$ 수준의 상태가 형성된다. 이로 인해 $L_2$ 오차는 $8.88 \times 10^{-2}$로, 최대 오차(Max Error)는 $3.59 \times 10^{-1}$로 산출되었다. 그럼에도 불구하고 정화된 비대칭성(Treated Asym)은 $2.30 \times 10^{-3}$ 대역으로 억제되며, 이는 대수적 정화 엔진이 해당 이산 공간이 수용할 수 있는 갤러킨 투영(Galerkin projection) 기반의 평형 상태를 도출함을 나타낸다.

3) Case C: 비선형 강도 스윕에 따른 비대칭 제어 (Varying $k_{nl}$)

마지막 시나리오는 $N_x=32$, $\sigma=10^{-1}$ 상태에서 비선형 강도 지수 $k_{nl}$을 $0.0$에서 $4.0$까지 변화시키며, 프레셰 도함수의 비대칭성이 대수적 구조에 미치는 영향을 추적한다.

[Figure 4.6 위치: 비선형 강도 $k_{nl}$ 증가에 따른 2D 비구조적 격자망의 국소 밀집(Mesh Deformation) 도식 삽입]

[Table 4.6 위치: 비선형 강도 $k_{nl}$ 변화에 따른 2차원 대수적 강건성 지표 표 삽입]

지수형 비선형 구배($\partial P/\partial u$)가 증가함에 따라 시스템 텐서의 교차 대칭성이 상실된다. 표 4.6에 따르면, $k_{nl}=4.0$ 조건에서 원시 비대칭성(Raw Asym)이 $3,304$ 규모로 증가하고 원시 조건수가 상승하였다. 그러나 내부 소산 제거 결과 잔류 비대칭성은 $6.28 \times 10^{-1}$로 억제되었다. 이 조건에서 조건수 안정화 비율은 최대 $979.1$배로 산출되었으며, 시스템은 추가적인 기하학적 통제 없이 대수적 정화 프레임워크만을 통해 $2.57 \times 10^{-3}$ 대역의 $L_2$ 오차 노름을 일관되게 유지하였다.
